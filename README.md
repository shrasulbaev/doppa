# Doppa

Приложение для изучения уйгурского языка для русскоязычных уйгуров, детей и взрослых. Android и iOS (Expo + React Native), бэкенд на Supabase.

## Что внутри

- **Регистрация:** приветствие → телефон или почта с кодом → выбор учителя (Алим или Райхан) и имени.
- **Уроки:** карта «Шёлкового пути» (раздел 1 — Кашгар), уровни из 6 слов: знакомство, выбор перевода, сборка слова из букв, поиск пар. Ошибки повторяются в конце урока.
- **Награды:** гранаты — жизни (5, один восстанавливается за 30 минут), пиала — серия дней, абрикосы — опыт (20 за новый уровень, 5 за повтор и за историю), звёзды за уровень.
- **Алфавит** (кириллица, 34 буквы), **История и культура** (рассказы с вопросами), **Разговорник** (все слова словаря по темам).
- **Озвучка:** у каждого слова кнопка прослушивания. Записи берутся из Supabase Storage. Пока файлов нет, аватар «проговаривает» слово анимацией, а приложение подсказывает, что голос появится позже.

## Запуск

```bash
npm install
npx expo start
```

Ключи Supabase лежат в `.env` (проект `doppa`). Если удалить `.env`, приложение перейдёт в демо-режим без сервера.

Expo Go подходит для проверки. Для сборок в магазины используйте EAS:

```bash
npx eas-cli@latest build --platform android
npx eas-cli@latest build --platform ios
```

Проверки: `npm run typecheck`, `npm run lint`, `npm test`.

## Supabase

Проект `doppa` (регион Франкфурт) уже создан: схема из `supabase/migrations` применена, словарь, уровни, алфавит и истории загружены из `supabase/seed.sql`.

Для нового проекта: впишите его URL и publishable key в `.env`, примените миграции (`supabase db push`) и выполните `supabase/seed.sql`.

Тестовый вход: пока в `.env` стоит `EXPO_PUBLIC_TEST_AUTH=1`, письма и SMS не отправляются, подходит код `000000`, прогресс хранится на устройстве.

Вход по почте: в Authentication → Email Templates → Magic Link замените ссылку на код `{{ .Token }}`, чтобы письмо приходило с 6 цифрами. Встроенная почта Supabase пишет только адресам участников организации и не чаще пары писем в час; для реальных учеников подключите свой SMTP (Authentication → SMTP Settings). Вход по телефону: Authentication → Providers → Phone, нужен SMS-провайдер, например Twilio.

## Контент

Словарь лежит в `content/source/uyghur_russian_dictionary_v1.xlsx`, курс (уровни, алфавит, истории) — в `content/course.json`. После правок:

```bash
pip install openpyxl
python3 scripts/import_content.py
```

Скрипт обновит `content/dictionary.json` (встроен в приложение для работы без сети) и `supabase/seed.sql`. Если Supabase подключён, приложение при запуске подтягивает свежий контент из базы.

## Как добавить записи голоса

Загрузите mp3 в бакет `audio` (Storage) с именами из колонки «audio file» словаря: `ug_0001.mp3`, `ug_0002.mp3` и так далее. Пересобирать приложение не нужно: кнопки прослушивания начнут играть записи сразу.

## Структура

- `src/app` — экраны (Expo Router)
- `src/components` — карта, аватар, иконки, кнопки
- `src/lib` — логика уроков и наград (с тестами), хранилище прогресса, Supabase, озвучка
- `supabase` — схема базы и данные
